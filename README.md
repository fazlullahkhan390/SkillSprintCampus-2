# SkillSprint ⚡
A Java + XML Android coursework demo with a micro-learning and self-improvement theme.

## Included
- Welcome/brand screen
- Login, register, forgot-password, and reset-password screens
- Basic local validation and simulated authentication/recovery
- Campus dashboard with four interactive skill mission cards
- Profile and logout
- Explicit Activity Intents
- LinearLayout forms, GridLayout dashboard, ConstraintLayout welcome
- `strings.xml`, day colors, and `values-night/colors.xml`

## Demo flow
Welcome → Login → Register → Dashboard → Profile → Logout.
Forgot Password → Reset Password → Login.

## Demo account
Register inside the app first. Password must be at least 6 characters.
The sample fallback login is any valid email with password `Green123`.
This is a learning prototype: credentials are in memory only and are not secure or persistent.

## Open
1. Open this folder in Android Studio (recent version).
2. Allow Gradle sync.
3. Run on an emulator or Android device.

## Repository

```bash

git add .
git commit -m "Add SkillSprint Android app"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```
